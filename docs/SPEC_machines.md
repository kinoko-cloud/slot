### 天井システム（3種類）
| 天井 | 条件 | 恩恵 |
|------|------|------|

### 天井短縮条件
| 条件 | 短縮後天井 |
|------|------------|
| 設定変更（リセット）後 | **666G+α**（朝イチ初当たりまでのみ） |
| リオチャンススルー後 | **666G+α**（次のBIGまで） |

### 超重要ポイント
- **REGを引いてもG数天井（天井1）はリセットされない**
- リオチャンス経由のREGはREG天井（天井2）にカウントされない
- 天井2の条件を満たす前に天井1に達成することが多い
- 設定変更時の666G短縮は**朝イチ初当たりまでのみ有効**
- サブ液晶の背景色でRB天井示唆（青→緑→赤）
- 有利区間リセットで**ジョーカーモード**突入

### スイカ天井（天井3）詳細
- **斜め揃いスイカのみ**カウント（上段揃いはチャンス目扱い）
- 通常時、RC中、ボーナス中を含む**全状態のスイカが対象**
- 有利区間リセットでスイカ天井もリセット
- 設定変更時は規定回数が優遇

### やめどき
- **BIG後30-40Gは必ず消化**（リオチャンス高確A+B滞在）
- 30G以降、高確演出がなければやめ
- REGスルー回数が多い場合（3-4回）はBBまで続行
- 天井が近い場合は続行
- **ピンチ目出現でステージ転落の可能性**（左リール青7狙い）

### リオチャンス高確示唆演出
- ミント出現 → 高確濃厚
- キャラ右から通過 → 高確濃厚
- JAPANステージ移行 → 高確濃厚
- 遅れ発生 → チェリー否定で本前兆濃厚
- レア役以外で連続演出発展
- 画面暗転頻発
- リール消灯頻発

### 設定判別ポイント

- スイカのST直撃（設定1: 0.4% → 設定6: 1.6%）

## 設定判別の共通ポイント

### 高設定の特徴
1. **初当たり確率が良い**（天井前に当たりやすい）
2. **連チャン率が高い**
3. **大ハマりが少ない**（設定6でも発生するが頻度は低い）
4. **天井到達率が低い**

### 低設定の特徴
1. **天井到達率が高い**
2. **連チャン率が低い**（単発・小連チャンが多い）
3. **大ハマりが多い**

### 注意点
- 大ハマりだけでは設定判別できない（高設定でも発生する）
- 初当たり確率は天井込みの数値に注意
- 差枚がマイナスでも高設定の可能性あり（特に北斗2）
- **天井で当たった回数を除外した「真の確率」で判断すべき**
