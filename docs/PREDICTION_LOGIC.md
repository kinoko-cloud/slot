# 台選び予測ロジック

## 概要

データ機から取得可能な情報のみを使い、「最終的に最大出玉になる台」を予測する。

---

## データ機から取得可能な情報

| 項目 | 説明 |
|------|------|
| ゲーム数 | 各ボーナス間のG数 |
| BB回数 | ビッグボーナス回数 |
| RB回数 | レギュラーボーナス回数 |
| ART回数 | AT/ART回数 |
| 獲得枚数 | 各ボーナスの獲得枚数 |
| 当選時刻 | 各ボーナスの当選時刻 |

**取得できない情報（使わない）：**
- 液晶表示（ステージ、演出示唆）
- あべし数
- スイカ回数などレア役
- サブ液晶の情報

---

## 指標の定義

### 1. 平均連チャン長（★★★最重要）

**定義：** 1回の連チャンで何連したかの平均

**計算方法：**
```
- 60G以下で連続して当たったものを1つの「セッション」とする
- 例：5G→3G→2G→200G の場合、最初のセッションは3連
- 各セッションの長さの平均を取る
```

**根拠：**
- 高設定 = 連チャン継続率が高い = 1回の連チャンが長い
- 低設定 = 連チャンしても短い（2-3連で終わる）
- 影響度: +130.3（最も重要な指標）

### 2. 平均獲得枚数（★★中程度）

**定義：** 1回の当たりあたりの平均獲得枚数

**計算方法：**
```
平均獲得枚数 = 総獲得枚数 / 総当たり回数
```

**根拠：**
- 高設定 = 連チャン時の継続が多い = 1回あたりの獲得が多い
- 影響度: +28.0

### 3. REG比率（★★中程度）

**定義：** 全当たりに占めるREGの割合

**計算方法：**
```
REG比率 = REG回数 / 総当たり回数
```

**根拠：**
- REG比率が低い ≒ 連チャンが長い（間接的な指標）
- 初当たりあたりのRB頻度は高設定も低設定もほぼ同じ
- 影響度: +28.0

**注意：**
- REG比率は「連チャン長」を間接的に反映している
- 単体では本質的な指標ではない

### 4. 天井到達率（★軽微）

**定義：** 500G以上でボーナスに当選した割合

**計算方法：**
```
天井到達率 = 500G以上での当たり回数 / 総当たり回数
```

**根拠：**
- 高設定 = 天井前に当たりやすい
- 影響度: +7.7

### 5. 単発率（★軽微）

**定義：** 連チャンせず終わった割合

**計算方法：**
```
単発率 = 1連で終わったセッション数 / 総セッション数
```

**根拠：**
- 高設定 = 単発が少ない傾向
- ただし影響度は低い: +0.0

### 6. 連チャン率（★軽微）

**定義：** 60G以下で当たった割合

**計算方法：**
```
連チャン率 = 60G以下での当たり回数 / 総当たり回数
```

**根拠：**
- 「平均連チャン長」の方が有効
- 影響度: +0.0

## 最適なスコアリング重み

```python
weights = {
    'avg_sess': 10,       # 平均連チャン長（★★★最重要）
    'renchain': 50,       # 連チャン率
    'avg_medals': 0.05,   # 平均獲得枚数
    'reg_rate': -50,      # REG比率（低いほど良い）
    'ceiling': -100,      # 天井到達率（低いほど良い）
    'single': -50,        # 単発率（低いほど良い）
}
```

### スコア計算式

```python
score = (
    平均連チャン長 × 10 +
    連チャン率 × 50 +
    平均獲得枚数 × 0.05 +
    REG比率 × (-50) +
    天井到達率 × (-100) +
    単発率 × (-50)
)
```

## 分析結果（アイランド秋葉原 SBJ）

### 時間帯別精度

| 時間 | 最高台的中率 | 平均超え率 | 平均順位 |
|------|-------------|------------|----------|
| 14時 | 47% | 80% | 3.3位 |
| 16時 | 47% | 93% | 2.5位 |
| 18時 | 40% | 93% | 2.5位 |
| 19時 | 67% | 93% | 2.0位 |
| 20時 | 60% | 93% | 2.3位 |

**発見：データが揃う遅い時間ほど精度が上がる**

### RB率と最終出玉の相関

| RB率 | 平均出玉 | 8000枚超率 |
|------|----------|------------|
| 0-10% | 7,811枚 | - |
| 10-20% | 6,071枚 | - |
| 20-30% | 4,893枚 | - |
| 30%+ | 2,196枚 | 0% |

**発見：RB率30%以上で8000枚出た台は0台**

### 初当たりあたりRBの分析

| | RB/初当たり | 初当たり数 |
|--|-------------|------------|
| 高出玉台 | 0.52 | 13.5回 |
| 低出玉台 | 0.49 | 11.0回 |
| 差 | -0.03 | - |

**発見：初当たりあたりRBはほぼ同じ。RB率が低く見えるのは連チャンが長いから。**

## 結論

### 最も重要な指標

1. **平均連チャン長** - 高設定の本質的な特徴
2. **平均獲得枚数** - 連チャン長と相関
3. **REG比率** - 連チャン長を間接的に反映

### 避けるべき台

- RB率30%以上 → 8000枚超の実績なし
- 単発が多い → 低設定傾向
- 天井到達が多い → 低設定傾向

### ロジックの限界

- 100%の予測は不可能（確率だから）
- データが少ない時間帯は精度が下がる
- 同じ高設定でもハマる日はある
